**Multi-head Video Classification for Sailing**: deep learning model that recognises boat type, tack side and point of sail (6 classes) from a single frame, using transfer learning on EfficientNetV2B2. Covers labelling, training, model comparison and evaluation. → [repo](https://github.com/nicolonucci/SailNet-Multi-Task-Frame-Classification)

**GPS Analysis of the 2025 Formula Kite World Championships**: reproducible Python pipeline comparing two elite athletes on speed over ground, VMG, start acceleration and tacking efficiency. → [repo](https://github.com/nicolonucci/GPS-Analysis-of-the-2025-Formula-Kite-World-Championships)
